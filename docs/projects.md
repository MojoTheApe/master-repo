# Project adoption index

This index points to project-owned settings, not a second operational inventory.

| Project | Workflow adoption |
| --- | --- |
| Master Repo | Maintains the shared standard; tooling completion with no app runtime |
| Task Tracker | Implements the optional contract; existing self/project configs remain unchanged until explicit adoption |
| ReactForge | Existing project flow/installer remain project-owned; no migration in MR-3 |
| New consumers | Select profile and stage option; complete registration and verification before ready |

Every consumer descriptor and runbook owns its actual version, environment and
exceptions. Local manual pull and stable package are separate profile choices.
No linked project is claimed upgraded merely because the shared standard changed.
