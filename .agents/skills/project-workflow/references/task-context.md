# Task relevance, requirements and compatibility

Use only with matching adopted `workflow.task_context` and Tracker
`task_context_policy` schema 1, execution v2/v3 and compatible fenced state. Read
the exact pinned engine's docs/TASK_CONTEXT.md or separated repository guide.
Never activate policy, manufacture evidence or invent an unsupported command.

Before editing, inspect complete requirements, current code/decisions, related
completed/pending work and dependencies. Record actual scope/main/Worker-bound
assessment. Ready work proceeds within authorization; clarification/superseded
findings grant no start. Ask the owner only for a material unresolved outcome or
authorization decision, not task age. New work obtains a real planning Issue
before a bound semantic assessment. Unchanged same-owner resume may reuse proof.

Only the exact terminal tracker-journal markers exclude work history. Keep all
criteria, checkboxes, dependencies and blockers outside. Headings alone never
exclude requirements. Old evidence keeps whole-body meaning; no silent rehash.

For an unchanged Approved source after forward main movement, use the supported
bounded source compatibility lane and actual independent Reviewer. Inspect semantic
dependencies, not just paths. Retain original source review/checks and append exact
compatibility proof. No author edit is needed merely to change a baseline.
Changed content/scope, conflicts, failed checks or divergence use normal author
return and independent source review. Release/takeover through owned commands;
elapsed time is never takeover authorization. Held compatibility blocks that
source's batch selection. Independent combined review, composition, current
admission and actual Stage/delivery checks remain unchanged.

New sources use the explicit v2 requirements digest; old proof stays conservative.
Existing activation follows reviewed official config, compatible writers and owned
idle maintenance, preserving queues, approvals/history and delivery. A new skill
or source merge does not perform a consumer upgrade or live activation.
