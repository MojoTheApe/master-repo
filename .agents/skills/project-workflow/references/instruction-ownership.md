# Instruction ownership and selected guidance

Start from the checked-in project reading map, exact descriptor and local Tracker
guide. The selected guide describes only its actual execution mode, Stage and
delivery target. Other supported routes are reference material; a new installed
skill never selects them.

Master owns the common lifecycle, profile guarantees, templates and this skill.
Tracker owns executable policy, commands, parser fields, ownership claims and
portable helper/reference closure. Consume its exact compatible output. Ordinary
opted-in engineering sources contain one task; explicitly adopted ordinary
capture has its genuine operation without an Issue alias. Reserved integration and promotion retain the
complete frozen member set and identity. Use final check-merge once, including
linkage, while retaining independent review and all required coverage.

Project docs/system and docs/runtime own product meaning, unique commands,
operational approvals, installers and access. Audited moves retain all original
substance and forwarding paths. Three-way upgrades preserve local knowledge and
genuine template ancestry. AI Skills mirrors the complete registered Master skill
at an immutable source; library packaging and employee installation are separate.

For a shared rule change, inspect both actual standalone export and final Master
output for every affected mode/Stage/target and policy absence. Check complete
relative-link/helper closure and actual selected PR fields, rather than relying
on a template-string test. Consult the pinned Master's docs/ownership.md for its
full source and verification responsibility map.
